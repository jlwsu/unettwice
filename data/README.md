# Sample data attribution

The photographic content in `10_aligned_samples/0` through `9` comes from the
[MegaDepth dataset](https://www.cs.cornell.edu/projects/megadepth/).

`target_gt.png`, `target_with_hole.png` and `align_ref_*.png` contain original or processed
MegaDepth photographic content. The examples are prepared for the UNet-Twice experiments.
